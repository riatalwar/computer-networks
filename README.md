# Welcome to Computer Netowrks 414/614 Fall 2026!
We will use this repository to release course assignments. 

## Getting started with each assignment

1. Read README-VM.md inside for each assignment directory to before starting the assignment. This will descibe setting up the virtual machines to provide a consistent development environment for each assignment.
2. Read README.md inside the Assignment directory to learn the problem statement and how to approach the solution.
3. Familiarize yourself with the code provided in the `starter_code` directory.
4. Complete the assignment, addressing all `TODO` sections in the code.
5. Submit to Gradescope.

Note: If you want to use Multipass and VM environment on your local machine, read README-VM-MULTIPASS.md inside the Assignment directory to learn how to set up your test environment using Multipass. Each assignment might have a different VM setup. Make sure you are using the correct VM setup!


## Getting help

- You will find a lot of useful hints in the README files. Make sure you read them multiple times before starting!
- Attend office hours.
